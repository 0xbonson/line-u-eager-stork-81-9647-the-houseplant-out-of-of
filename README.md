# The Houseplant Out-of-Office

```
I am out of the office dying of thirst while you water the plastic succulent on the bookshelf.
```

### About the Joke
A humorous out-of-office message from a neglected houseplant expressing indignant frustration over its owner mistakenly watering an artificial succulent instead.
